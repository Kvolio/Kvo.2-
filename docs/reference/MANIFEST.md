# HISTORICAL REFERENCE PACK

The categorised reference board (§8), and the index every critic reads before it
looks at a render. **These images are the authority.** Where one of them
contradicts a published figure or anything in `../TIGER-CONFIGURATION.md`, the
image wins and the document is corrected.

## Reading the evidence

A photograph is evidence of **one vehicle on one day**, not of the production
standard. Before changing the model because of an image, classify what it shows:

- **production-standard** — reproduce it
- **vehicle-specific modification** — do not generalise it across the Tiger
- **battle damage** — do not model it as standard
- **photographic artifact** — lighting, angle, film, retouching, colourisation
- **different production batch** — check it against the configuration lock; if it
  belongs to a later build state it is out of scope

Where references disagree, find the feature common to several and let the
configuration lock break the tie. The goal is not to copy one photograph — it is
to reconstruct the configuration the evidence represents.

### Known caveats in this pack

- `231-colour-road-left-rear-quarter.webp` is **colourised**, not original
  colour film. Use it for pattern and marking placement; do not trust the exact
  hues.
- `battle-damaged-three-quarter-front-right.jpg` shows a vehicle that has been
  hit many times. The damage is specific to that tank and must not be modelled
  as standard. Its value is the undamaged geometry underneath.
- Turret numbers differ between photographs (211, 231, 12). The configuration
  lock specifies **S13** for the vehicle being modelled; the photographs settle
  the *style, size and placement* of the numerals, not the digits.
- `scale-model-plan-view.jpg` is a modeller's work, not a wartime photograph.
  It is a guide to layout and relative position, and is not evidence for detail.
